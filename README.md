# دليل المقاسات لمنتجات سلة

تطبيق لإدارة جدول مقاسات مستقل لكل منتج من لوحة تحكم عربية، وإظهار زر **«دليل المقاسات»** في صفحة المنتج داخل متجر سلة.

يعتمد المشروع على **FastAPI** و**PostgreSQL على Neon**، ويُشغّل على **Render**. يحتفظ المستودع باسم `salla-pageindex-api`، لكن وظيفة التطبيق الحالية هي دليل المقاسات.

## المزايا

- ربط المتجر عبر نمط سلة السهل `Easy Mode` واستقبال حدث `app.store.authorize`.
- مزامنة المنتجات من سلة مع الصور وSKU والأسعار والحالة.
- إنشاء جدول مقاسات لكل منتج، بصفوف وأعمدة قابلة للتعديل.
- هياكل فارغة للفساتين والبلايز والبناطيل والتنانير دون أرقام مقاسات افتراضية.
- التمييز بين قياسات الجسم وقياسات القطعة نفسها.
- التحويل بين السنتيمتر والإنش للقيم والنطاقات الرقمية.
- أعمدة نصية مستقلة لرموز المقاسات مثل EU وUK، تُعبّأ يدويًا.
- إضافة تعليمات القياس وملاحظات القَصّة والقماش وتعديل لون الدليل.
- معاينة الجدول ونسخه من منتج آخر كمسودة مستقلة.
- حفظ المسودات دون تغيير النسخة المنشورة، ونشر الجدول أو إيقاف ظهوره.
- دخول خاص بالمسؤول بكلمة مرور وجلسة محمية.

## هيكل المشروع

| المسار | الوظيفة |
| --- | --- |
| `main.py` | تطبيق FastAPI وربط سلة واستقبال Webhooks وتهيئة الجداول |
| `dashboard.py` | دخول الإدارة ومزامنة المنتجات وسجل العمليات |
| `size_guides.py` | إدارة جداول المقاسات ونشرها ومسارات العرض العام |
| `requirements.txt` | مكتبات Python المطلوبة |
| `static/dashboard.html` | واجهة لوحة التحكم العربية |
| `static/size-guide-admin.js` | محرر المقاسات وربطه بواجهة API |
| `static/size-guide-renderer.js` | عرض الجدول والنافذة وتحويل الوحدات |
| `static/size-guide-widget.js` | إدراج زر الدليل في صفحة المنتج |
| `test_dashboard.py` | اختبارات الدخول والمزامنة بمحاكاة الخدمات |

قد تتضمن حزمة التسليم أيضًا `test_size_guides.py` لاختبارات المسودات والنشر وعزل المتاجر، و`SALLA_APP_SNIPPET.js` كمقطع جاهز للمتجر التجريبي.

## متغيرات البيئة

أضف القيم في **Render → Environment**. لا تضع كلمات المرور أو التوكنات في GitHub.

| المتغير | الاستخدام |
| --- | --- |
| `DATABASE_URL` | رابط اتصال قاعدة بيانات PostgreSQL، مع اتصال TLS |
| `DATABASE_URL_UNPOOLED` | اختياري: اتصال مباشر تستخدمه تهيئة الجداول الأساسية |
| `SALLA_WEBHOOK_SECRET` | مفتاح حماية التنبيهات السري من سلة، عند اختيار حماية `Token` |
| `DASHBOARD_PASSWORD` | كلمة مرور الإدارة، لا تقل عن 12 حرفًا |
| `DASHBOARD_SESSION_SECRET` | قيمة عشوائية سرية لا تقل عن 32 حرفًا لتوقيع الجلسات |

المتغيرات التالية تخص مسار OAuth المخصص الموجود في المشروع، وليست مطلوبة لاستقبال التوكنات في `Easy Mode`:

- `SALLA_CLIENT_ID`
- `SALLA_CLIENT_SECRET`
- `SALLA_REDIRECT_URI`

لتوليد سر جلسة عشوائي على جهازك:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

ضع الناتج في `DASHBOARD_SESSION_SECRET` مباشرة، ولا ترفعه إلى المستودع.

## النشر على Render

1. اربط خدمة Render بمستودع GitHub.
2. ضع `main.py` وبقية ملفات Python في جذر المستودع، وملفات الواجهة داخل `static`.
3. اترك **Root Directory** فارغًا عندما تكون الملفات في جذر المستودع.
4. أضف متغيرات البيئة المطلوبة.
5. استخدم أمر البناء:

   ```bash
   pip install -r requirements.txt
   ```

6. استخدم أمر التشغيل:

   ```bash
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```

7. اختر **Deploy latest commit** وانتظر ظهور **Live**.
8. افتح `/dashboard` على نطاق الخدمة وسجّل الدخول.

رابط لوحة التحكم في الخدمة الحالية:

https://salla-pageindex-api.onrender.com/dashboard

يُنشئ التطبيق الجداول المطلوبة عند بدء التشغيل إذا لم تكن موجودة. تحديث الواجهة لا يتطلب حذف المنتجات أو التوكنات أو إعادة إنشاء قاعدة البيانات.

> عند تحديث مشروع يعمل بالفعل، احتفظ بمتغيرات البيئة الحالية واستبدل الملفات المطلوبة فقط.

## ربط المتجر في سلة

1. افتح إعدادات التطبيق في بوابة شركاء سلة.
2. اختر **النمط السهل — Easy Mode**.
3. ضع رابط استقبال التنبيهات:

   ```text
   https://salla-pageindex-api.onrender.com/webhook
   ```

4. اختر خطة حماية التنبيهات **Token**.
5. اجعل قيمة `SALLA_WEBHOOK_SECRET` في Render مطابقة لمفتاح التنبيهات السري في سلة.
6. ثبّت التطبيق على المتجر التجريبي ووافق على الصلاحيات.
7. إذا كان التطبيق مثبتًا بالفعل ولم تُحفظ بيانات التفويض، استخدم **إعادة إرسال رمز الوصول للتطبيق** من سلة.

يحفظ المعالج رمز الوصول ورمز التحديث تحت معرّف المتجر. لا يعرضهما في لوحة التحكم أو في كود الزر العام.

## إنشاء جدول مقاسات ونشره

1. سجّل الدخول إلى لوحة التحكم واختر المتجر.
2. اضغط **مزامنة المنتجات** إذا لم تكن المنتجات موجودة أو احتاجت تحديثًا.
3. بجانب المنتج المطلوب، اختر **إضافة مقاسات** أو **تعديل الجدول**.
4. اختر قياسات الجسم أو قياسات القطعة ووحدة إدخال البيانات.
5. أضف الصفوف والأعمدة وأدخل قياسات المنتج الفعلية.
6. اكتب تعليمات القياس وأي ملاحظات عن القَصّة أو القماش.
7. راجع **المعاينة**، ثم اختر **حفظ مسودة** أو **نشر للعميل**.

### قواعد النشر

- أسماء المقاسات مطلوبة وغير مكررة.
- تُستكمل جميع الخلايا قبل النشر؛ يمكن كتابة `—` للخانة غير المنطبقة.
- الحد الأقصى: 30 مقاسًا و10 أعمدة، إضافة إلى عمود اسم المقاس.
- حفظ المسودة لا يغيّر النسخة التي يراها العميل.
- إيقاف الظهور يخفي الجدول ويحتفظ بالمسودة.
- نسخ جدول من منتج آخر لا يربط الجدولين؛ راجع أرقام المنتج الجديد قبل نشره.
- لا تُفترض معادلات تحويل دولية للمقاسات؛ أدخل أكواد EU وUK وغيرها من بيانات المنتج المعتمدة.

## إضافة الزر إلى متجر سلة

بعد نشر جدول لمنتج ظاهر في المتجر:

1. من لوحة التحكم اختر **تركيب زر المتجر**.
2. تأكد من اختيار المتجر الصحيح، ثم اضغط **توليد كود المتجر المحدد** وانسخ الكود.
3. افتح تطبيقك في بوابة شركاء سلة، وانتقل إلى **App Snippets**.
4. أضف مقطع JavaScript والصق الكود كما هو، دون إضافة وسوم `<script>`.
5. احفظ المقطع واختبر صفحة المنتج في المتجر التجريبي.

يحتوي المقطع على رابط الخدمة ومعرّف المتجر فقط. لا يحتاج إلى توكن سلة أو كلمة مرور الإدارة.

### موضع الزر

يحاول المقطع إدراج الزر بجانب خيارات المنتج أو زر إضافته للسلة. إذا لم يتوفر موضع مناسب، يظهر كزر عائم أسفل صفحة المنتج.

في قالب مخصص، يمكن تحديد الموضع باستخدام عنصر مثل:

```html
<div data-size-guide-anchor></div>
```

يظهر زر الدليل فقط عندما يكون للمنتج جدول منشور، ويكون المنتج موجودًا في الكتالوج المحلي بحالة معروضة أو نافدة. لا يُعرض للمنتجات المخفية أو التي لا تملك جدولًا منشورًا.

## المسارات الرئيسية

| المسار | الغرض |
| --- | --- |
| `/dashboard` | لوحة الإدارة |
| `/webhook` | استقبال تنبيهات سلة الموثقة |
| `/dashboard-api/stores` | المتاجر المربوطة؛ يتطلب جلسة إدارة |
| `/dashboard-api/sync` | بدء المزامنة؛ يتطلب جلسة إدارة |
| `/dashboard-api/size-guides` | قائمة جداول المتجر؛ يتطلب جلسة إدارة |
| `/dashboard-api/size-guides/{product_id}` | قراءة أو حفظ جدول منتج؛ يتطلب جلسة إدارة |
| `/public/size-guides/{merchant}/{product_id}` | عرض النسخة المنشورة فقط |
| `/size-guide-widget.js` | ملف زر صفحة المنتج |
| `/size-guide-renderer.js` | ملف عرض نافذة المقاسات |

الجداول المنشورة بيانات عامة لعملاء المتجر. المسودات وواجهات التعديل تبقى خلف تسجيل الدخول.

## الاختبارات

ثبّت متطلبات المشروع ومكتبة عميل الاختبارات:

```bash
pip install -r requirements.txt
pip install httpx
python -m unittest discover -p "test_*.py" -v
```

عند وجود ملفَي الاختبارات، تغطي الاختبارات المحلية الدخول والمزامنة وعزل المتاجر وحماية المسودات والنشر وإيقاف الظهور. تستخدم الاختبارات محاكاة لقاعدة البيانات وسلة، ولا تستبدل اختبار المتجر الحقيقي.

### اختبار التفعيل في المتجر

1. احفظ جدولًا كمسودة وتأكد من عدم ظهوره للعميل.
2. انشر الجدول وأعد تحميل صفحة المنتج.
3. افتح الزر وتحقق من اسم المنتج وأرقامه.
4. اختبر التحويل: `2.54 سم = 1 إنش`.
5. عدّل المسودة دون نشر وتأكد من بقاء النسخة المنشورة السابقة.
6. أوقف الظهور وأعد تحميل الصفحة.
7. اختبر منتجًا ثانيًا بلا جدول، ثم اختبر العرض على الجوال.

## حل المشكلات

| المشكلة | ما يجب التحقق منه |
| --- | --- |
| لوحة التحكم لا تفتح | اكتمال نشر أحدث الملفات ووجود `static/dashboard.html` |
| رسالة إعدادات دخول لوحة التحكم | طول وقيم `DASHBOARD_PASSWORD` و`DASHBOARD_SESSION_SECRET` |
| المنتجات لا تظهر | وجود متجر مربوط، ثم صلاحية قراءة المنتجات ونتيجة المزامنة |
| رمز الوصول منتهي | إعادة إرسال رمز الوصول من سلة ثم إعادة المزامنة |
| الزر لا يظهر | نشر الجدول، حالة المنتج، صحة المتجر المحدد في المقطع، وحفظ App Snippet |
| النافذة لا تُحمّل | توفر خدمة Render والسماح بتحميل ملفات الخدمة واتصالها من قالب المتجر |
| تعارض عند حفظ الجدول | أُجري تعديل من نافذة أخرى؛ احتفظ بتعديلاتك ثم أعد فتح أحدث نسخة |

## حدود النسخة الحالية

- الإدارة مخصصة لمسؤول واحد بكلمة مرور واحدة لجميع المتاجر المربوطة، وليست نظام حسابات منفصلًا لكل تاجر.
- يدعم التطبيق جدولًا مستقلًا واحدًا لكل منتج، ولا يقترح المقاس المناسب تلقائيًا.
- لا يتضمن التطبيق الحالي محرك PageIndex للبحث الذكي أو واجهة بحث للعملاء.
- تجديد توكنات سلة تلقائيًا غير منفّذ؛ تعرض المزامنة رسالة لإعادة إرسال رمز الوصول عند انتهائه.
- المزامنة تعمل داخل عملية Render؛ تجنب إعادة النشر أثناء تشغيلها. التشغيل الكبير يحتاج عامل مهام دائمًا.
- موضع الزر قد يختلف حسب القالب، ويجب اختباره على المتجر الفعلي.
- النافذة المفتوحة تعرض النسخة التي جُلبت وقت فتحها؛ تجلب أحدث نسخة عند إعادة فتحها.
- إذا كانت خدمة Render غير متاحة أو تستغرق وقتًا للاستيقاظ، قد لا يظهر الدليل حتى عودة الخدمة وإعادة تحميل الصفحة.
